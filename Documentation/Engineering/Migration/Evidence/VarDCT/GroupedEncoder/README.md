# Grouped VarDCT encoder checkpoint

Pinned predecessor: `57e81cb9e2411d1efac435b429a306a031744c1e`; contract 0.10.0. The writer now emits one DC/metadata section per 2048-pixel region and appends deferred alpha to each 256-pixel AC group. Gradient prediction restarts at every group boundary. Compact transform metadata is filtered by DC-region origin while AC coefficients retain their original offsets. Histogram collection uses the same group-local token traversal as emission, without storing frame-sized token arrays or copying a full alpha image.

The internal admission limit is 4096 pixels per dimension and 4,194,304 total pixels, with the existing stricter caller budget/deadline limits. The corresponding hierarchy geometry guard is changed in the coordinated analysis checkpoint. This extends narrow/rectangular images beyond one DC group while preserving the earlier maximum pixel count. It does not admit a four-DC-group square, whose dimensions would exceed that pixel limit. Associated alpha remains unsupported. Public capability changes are separate integration work.

Twelve new streams were accepted by the existing pinned scalar libjxl build. Eight varied fixtures cover horizontal/vertical AC and DC group boundaries, a two-dimensional AC grid, odd edges, the 4096 dimension limit, greyscale/RGB, 8/16-bit precision, alpha, and hierarchical prepared-control output across DC boundaries. Four zero-input fixtures replace the former 257-pixel-alpha rejection assertions with exact independently accepted byte assertions. All existing historical DCT8/prepared/small/hierarchical fixture bytes remain unchanged.

The unchanged numerical gate uses Float32 explicit sRGB decoded by independent pinned libjxl, rounded to meaningful integer precision: peak ≤2 LSB, RMS ≤0.5 LSB, alpha exact against both source and oracle. All twelve pass; observed maximum peak is 1 LSB and maximum RMS is 0.15803 LSB. This does not replace or erase earlier ARM NEON integer differences. Input formula, emitted streams, oracle samples, exact measurements, and probe/check sources are retained here and in `Tests/SwiftJXLCoreTests/Fixtures/VarDCT/GroupedEncoder`.

Final debug passes 15 declarations / 74 cases. Combined ASan and TSan each pass 30 declarations / 110 cases, including that debug subset and the coordinated transform-workspace tests, with zero skips. Exact commands, logs and hashes are in `validation.json`.

New tests bind encoded bytes to the oracle corpus, decode to the existing numerical/alpha limits, verify frame flags and section count, preserve padded big-endian planar source bytes, and reject unqualified geometry/insufficient workspace. Source borrows remain synchronous and no raw pointer escapes. Storage audit shows zero additional final-image allocations; it is not peak-memory instrumentation. New compact metadata index arrays are admitted with capacity headroom before allocation. Existing source cancellation and policy tests remain in the affected group.

Source review by the coordinating agent found no blocking DC-region, compact-metadata, alpha-prediction or prefix-stream defect. AC transform origins remain within 32-cell boundaries, which align with 256-cell DC groups. Initial probing found the hierarchy's earlier 2048 dimension guard; that guard was coordinated with its owner before requalification. No external codec library was rebuilt: the already-qualified bounded oracle wrapper from the GroupedDecoder checkpoint was reused.

Remaining scope includes full predecessor dimension/area coverage, complex encoder profiles, broad malformed/fuzz campaigns, controlled grouped performance and peak-memory measurements, hosted platform checks and the original ARM numerical disposition. This is a feature checkpoint, not completed migration or release qualification.
